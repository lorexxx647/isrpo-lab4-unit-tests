# Документация проекта «calculator»

## Общее описание решения

`calculator` — учебный Python-модуль, реализующий базовые арифметические операции. Используется как библиотека и не имеет пользовательского интерфейса.

Модуль содержит следующие функции:
- `add(a, b)` — сложение;
- `subtract(a, b)` — вычитание;
- `multiply(a, b)` — умножение;
- `divide(a, b)` — деление;
- `power(a, b)` — возведение в степень;
- `sqrt(a)` — извлечение квадратного корня.

Для некорректных входных данных (например, деление на ноль) модуль генерирует исключение `ValueError`.

## Описание функций

### `add(a, b)`
Возвращает сумму двух чисел.

Пример вызова:
    add(2, 3)  # Вернет 5

### `subtract(a, b)`
Возвращает разность двух чисел.

Пример вызова:
    subtract(10, 4)  # Вернет 6

### `multiply(a, b)`
Возвращает произведение двух чисел.

Пример вызова:
    multiply(3, 4)  # Вернет 12

### `divide(a, b)`
Возвращает частное двух чисел. Бросает `ValueError`, если делитель равен нулю.

Пример вызова:
    divide(10, 2)  # Вернет 5.0
    divide(10, 0)  # Вызовет ValueError

### `power(a, b)`
Возвращает число `a`, возведенное в степень `b`.

Пример вызова:
    power(2, 3)  # Вернет 8

### `sqrt(a)`
Возвращает квадратный корень числа `a`. Бросает `ValueError`, если число отрицательное.

Пример вызова:
    sqrt(9)   # Вернет 3.0
    sqrt(-1)  # Вызовет ValueError
